# MechrevoMode

MechrevoMode 是一个常驻托盘的机械革命档位切换工具

程序是纯 Go 写的单个 exe，无运行时依赖、无安装包。

### 设置界面

一张模式表，八行（3 个内置档位 + 5 个自定义档位）：

| 列 | 说明 |
| --- | --- |
| 显示 | 是否出现在托盘右键菜单 |
| 模式名称 | 随便改，可带 emoji |
| 原始模式 | **只读**。这行到底对应哪个硬件档位（办公 / 均衡 / 狂暴 / 自定义 · 档位 N）。名称改乱之后靠它认路 |
| 图标 | 托盘图标上的白色字母，单字符 |
| 底色 | 点开取色，或直接填十六进制 |
| 电源计划 | 节能 / 平衡 / 高性能 / 卓越性能 |

表格下面是**启动命令**：程序启动后延迟 N 秒执行一次命令（典型用途是 `ryzenadj` 降压）。可以勾「需要管理员权限」，另有「立即运行」按钮方便试。输出不打印，成功失败看状态栏和气泡。

顶部两个开关：

- **开机自启动** —— 见下方「开机自启动」。
- **以管理员身份运行** —— 写当前用户的兼容性标志，和你在「属性 → 兼容性 → 以管理员身份运行此程序」里勾是同一处，随时能自己撤掉。

底部：恢复默认外观 / 保存设置 / 退出程序。

## 环境要求

- **已安装机械革命官方控制中心**（提供 `GCUBridge` 服务和 `GCUService.exe`）。不要求它正在运行，但文件得在。

## 命令行参数

都是自检 / 调试用的，跑完就退出，不影响正在运行的实例。

```text
MechrevoMode.exe [options]
```

| 参数 | 说明 |
| --- | --- |
| `-show` / `--show` | 启动后直接打开设置界面 |
| `-switch <key>` | 启动后单次切到指定档位（key 见 `config.json`） |
| `-dump-gcu` | 打印 GCU 后端现状（服务状态、端口、进程）到 `data\gcu.txt` |
| `-dump-plans` | 导出电源计划枚举结果到 `data\plans.txt` |
| `-dump-icons` | 把各尺寸托盘图标渲染成对照图 `data\icons\sheet.png`，并打印字模留白余量 |
| `-test-plans` | 逐个试切内置电源方案，测完还原 |
| `-test-elevate` / `-test-elevate-off` | 写入 / 清除「以管理员身份运行」标志 |
| `-test-gcu-launch <exe>` | 验证「静默拉起 GCU 后端」这条兜底路径 |

## 从源码构建

双击 `build.bat` 即可，产物落在 `build\MechrevoMode.exe`。手动构建等价于：

```bash
go test ./...
go build -trimpath -ldflags "-s -w -H windowsgui" -o build/MechrevoMode.exe .
```

`-H windowsgui` 是必须的，否则会多出一个控制台窗口。注意这样构建出来的程序**没有 stdout**，所有输出都进 `data\log.txt`。

依赖只有 `github.com/eclipse/paho.mqtt.golang`（MQTT 客户端），其余全是标准库 + `syscall`。没有 cgo，产物就是单个 exe。

工作原理、MQTT 协议细节、程序图标怎么嵌进去、构建脚本踩过的坑，都在 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 故障排查

- **双击没反应** —— 先确认是不是已经有一个实例在跑（本工具是单实例的）。其次检查 exe 是不是被云同步目录「释放空间」变成了占位文件。
- **悬停提示一直显示「未连接」** —— 说明没连上 GCU 的 MQTT 后端。用 `-dump-gcu` 看 `GCUBridge` 的服务状态和进程。程序会自己尝试把后端拉起来（间隔 40 秒），也可以手动打开一次官方控制台。
- **切了档位但提示里的数值没跟着变** —— GCU 在切换过程中会先回几条旧状态，本工具有一段「落定期」只认与目标一致的回报，稍等 2~3 秒。
- **托盘图标不见了** —— 先看 `data\log.txt` 的尾巴。Explorer 崩溃重启这种情况程序会自己挂回去；其它情况看日志里有没有 `Shell_NotifyIcon` 相关报错。

## 已知限制

- **UAC 提示**。勾了「以管理员身份运行」且系统 UAC 开着时，每次启动会弹一次授权窗口；走计划任务的开机自启不弹。
- **模式编号沿用官方枚举**：0 办公 / 1 均衡 / 2 狂暴 / 3 自定义。自定义模式下有 5 个档位，本工具的自定义档位就是这 5 个。
- **只针对机械革命 + GCU** 这套后台。换成没有 GCU 的机器，连不上就是连不上。
